### 🧠 HelpFull - Plataforma de Monitoramento e Apoio Emocional

> *Projeto desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas na Fatec Ourinhos.*

O **HelpFull** é uma aplicação web focada em saúde mental e autocuidado. O objetivo é oferecer um espaço seguro e privado onde o usuário pode monitorar sua evolução emocional, identificar padrões de humor e receber acolhimento imediato.

**🛠️ Principais Funcionalidades:**

* **🤖 Chatbot de Acolhimento:** Assistente virtual implementado para simular escuta ativa e fornecer conselhos imediatos em momentos de angústia.
* **📊 Dashboards Analíticos:** Geração de gráficos dinâmicos que exibem o "Sentimento Predominante do Mês" e a frequência de uso, transformando dados subjetivos em métricas visuais.
* **📝 Diário de Escrita Expressiva:** Ferramenta para registro livre de pensamentos, baseada na técnica de Pennebaker.
* **📅 Histórico Cronológico:** Calendário interativo para navegação e revisão de registros passados.
* **😊 Identificação Emocional:** Sistema de categorização de humor com opções pré-definidas (Feliz, Ansioso, Grato, etc.) para padronização de dados.
